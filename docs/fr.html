Rien au milieu

La plupart des connecteurs te demandent de confier tes identifiants Garmin au serveur de quelqu’un d’autre. Celui-ci tourne sur une machine que tu contrôles. L’installeur met tout en place sous ton propre utilisateur, enregistre le connecteur comme service qui démarre avec la machine (systemd ou launchd) et affiche les liens de connexion.

Installer

Linux et macOS. Le script installe Tailscale quand c’est nécessaire (--tailscale, --tailscale-serve, --funnel) et --no-sudo interdit toute élévation de privilèges, implicite en root.

--funnel expose l’endpoint MCP et la surface OAuth à tout Internet : le token d’accès est le seul verrou. --tailscale-serve est privé, mais ne fonctionne pas avec « Ajouter un connecteur personnalisé » de claude.ai/Claude Desktop : cette fonctionnalité est appelée depuis les serveurs d’Anthropic, jamais ton tailnet. Utilise-le seulement pour des clients qui tournent directement sur une machine de ton tailnet (Claude Code, etc).

Connecter un client

Les clients locaux appellent le connecteur en direct et peuvent utiliser une URL privée. « Ajouter un connecteur personnalisé » de claude.ai est appelé depuis les serveurs d’Anthropic, il lui faut donc toujours une adresse HTTPS publique.

  1. Obtenir une adresse HTTPS publique

    Seulement nécessaire pour la ligne « Ajouter un connecteur personnalisé » ci-dessus. --funnel à l’installation donne une adresse permanente https://<machine>.<tailnet>.ts.net qui survit aux redémarrages (voir l’avertissement ci-dessous). Le bouton Create HTTPS link de la page de configuration donne à la place un tunnel Cloudflare rapide, public aussi, et son URL change à chaque redémarrage. La config locale de Claude Code / Desktop peut à la place utiliser une adresse privée --tailscale-serve ou l’URL à jeton classique : pas besoin d’exposition publique là.

  2. Ajouter le connecteur

    Colle l’URL HTTPS de base suivie de /garmin/, sans jeton.

  3. Valider

    claude.ai ouvre la page d’autorisation du connecteur : colle le jeton d’accès donné par garmin-mcp url ou par la page de configuration, puis approuve. L’autorisation persiste.

Funnel et les tunnels rapides sont publics

Quiconque obtient le token d’accès peut appeler l’endpoint MCP à travers eux : le token est le seul verrou (connexion, santé et déconnexion restent privées, les chemins inconnus renvoient 404). --tailscale-serve est privé mais ne peut pas du tout être utilisé pour « Ajouter un connecteur personnalisé » de claude.ai/Desktop : ce flux est toujours appelé depuis les serveurs d’Anthropic, jamais ton tailnet.

Si ça échoue : DNS en cours de propagation

Si claude.ai n’atteint pas le serveur juste après l’activation de Funnel, attends quelques minutes. Si ça persiste, renomme la machine dans la console Tailscale (un nom DNS neuf résout immédiatement) et relance l’installeur.

Comment ça marche

Un seul processus sur ta machine, deux entrées, et une seule est joignable depuis Internet.

  • navigateur

    Se connecte sur la page de configuration : le mot de passe part directement vers Garmin SSO et n’est jamais stocké

  • garmin-mcp

    Le connecteur, sur ta machine. Jetons OAuth dans ~/.config/garmin-mcp/. Dialogue avec Garmin SSO et l’API Connect

  • /garmin/

    Endpoint MCP : le jeton de l’installation en ?token=, en préfixe de chemin /t/<token>/garmin/, ou en en-tête Bearer. Clients locaux, en direct : Claude Code, config locale de Desktop, ou --tailscale-serve pour tout client sur ton tailnet

  • Entrée HTTPS publique

    Funnel ou tunnel rapide : seuls l’endpoint MCP et la surface OAuth répondent ; connexion, santé et déconnexion restent privées, tout le reste renvoie 404. claude.ai / « connecteur personnalisé », appelé depuis les serveurs d’Anthropic (OAuth 2.1 + PKCE)

Avec Funnel ou un tunnel rapide, les scanners qui sondent l’adresse publique, c’est normal : tout ce qu’ils touchent renvoie 404. --tailscale-serve évite totalement ça pour les clients locaux directs, mais c’est une adresse séparée et privée que « Ajouter un connecteur personnalisé » de claude.ai ne peut jamais joindre : ce flux a toujours besoin de l’adresse publique.
